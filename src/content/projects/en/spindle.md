Spin a wheel, get an answer, move on. Spindle exists because the cost of
deciding where to eat is almost always higher than the cost of being wrong about
it.

Built with **React Native and Expo**, shipped to both stores from one codebase
through a GitHub Actions pipeline that handles the build and signing. It is a
small app, which is the point: the interesting engineering is in the release
loop, not the wheel.
